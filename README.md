## Description

Generative AI can speed up routine coding work, but pharma cannot use black-box output or ungoverned data flows. This three-hour hands-on workshop will show you how to use Posit Assistant - a "bring your own model" AI feature in the free, open-source Positron IDE - to accelerate exploratory analysis and reporting while staying fully in control. Connect the LLMs your organization has already approved, then use them to draft the R or Python code behind summary tables, lists, figures, and reports across genomics, proteomics, PK, drug discovery, manufacturing, and clinical trial work. Your data never goes to the model nor does the model return results; the model focuses on generating code for you to run on your data locally. You set the methodology at every step and approve every line of code before it runs. We'll also cover monitoring and optimizing token usage. Positron is free to install and already available in many pharma companies through Posit Workbench.
